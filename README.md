# Soccer Robots Desktop Application

A winforms application in which I used connected mode, Linq and dataset.

## Tech stack

- C# / .NET
- Windows Forms
- Target framework: v4.8
- ADO.NET (SqlClient)
- ADO.NET disconnected mode (DataSet / DataAdapter)
- LINQ

## Contents

- Forms: AddRobotForm, AddTeamForm, Form1
- Classes: AddModifyMatch, Match, MatchDashBord, MatchStatistics, Robot, RobotDashbord, Team, TeamDashbord
- SQL scripts: `SQLQuery1.sql`, `SQLQuery2.sql`, `SQLQuery3.sql`

## How to run

Open `SoccerRobots_Desktop_Application.sln` in Visual Studio (Windows) and press F5. The app connects to SQL Server: update the connection string to your own server first.
